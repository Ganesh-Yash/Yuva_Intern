Employee Attrition Risk Application

An end-to-end machine learning product: preprocess, train, test, serialise with Joblib/Pickle, and deploy a FastAPI prediction service with a simple HR UI.

Week 4 of the ML internship · 11 September 2026

The problem

  • HR wants an early signal that an employee may leave.
  • Weeks 1–3 built cleaning, models, clustering and evaluation on this schema.
  • Week 4 ships the model: a real API a person can call, not a notebook cell.

What was built

  • sklearn Pipeline: StandardScaler + OneHotEncoder + Random Forest.
  • GridSearchCV on F1, then a clean hold-out test.
  • Artefacts: attrition_pipeline.joblib and .pkl.
  • FastAPI: POST /predict, plus health, metadata, docs and UI.

Data & features

  • Numeric: age, tenure, salary, performance.
  • Categorical: gender, department, city.
  • Target: Attrition Yes/No (imbalanced).
  • Preprocessing lives inside the Pipeline.
  • The API cannot skip a step or scramble dummy columns.
  • Unknown categories are ignored, not fatal.

Evaluation (hold-out)

Accuracy is reported, but F1 and ROC-AUC are the numbers that matter on an imbalanced leave class. Full tables are in the Word report.

  • Confusion matrix — missed leavers vs false alarms.
  • ROC curve — ranking quality across thresholds.
  • The API returns a probability and Low/Medium/High band so callers can pick their own cutoff.

Serialisation

  • Joblib — what the server loads at startup. Efficient for sklearn trees.
  • Pickle — same object, standard-library format, submitted alongside.
  • Load only trusted files: both formats can execute code on unpickle.

API contract

  • POST /predict — JSON employee in, attrition + probability + risk band out.
  • GET / — HR form. Uses relative /predict, not localhost.
  • GET /docs — OpenAPI. GET /health — liveness.

How to run

cd week4-ai-project-deployment

python3 train_model.py  (optional rebuild)

uvicorn app:app --host 0.0.0.0 --port 8000

Open the service origin. Bind address is 0.0.0.0 so a preview proxy can reach it.

Takeaways

  • A model is not deployed until preprocessing ships with it.
  • Joblib/Pickle turn a fitted Pipeline into a file the API can load once.
  • FastAPI gives validation, JSON, docs and a UI from one process.
  • Next steps on real data: drift monitoring, fairness review, threshold policy.
